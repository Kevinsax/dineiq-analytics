# screenshots/

Add screenshots here before the final submission -- the SRS's GitHub Repository
checklist (Section 1.10, Item 12) explicitly requires screenshots.

Minimum set to include:
1. Executive Dashboard (home page) with real KPI numbers visible
2. Menu Intelligence page (classification scatter plot)
3. Customer Intelligence page (RFM segments)
4. Wastage dashboard
5. Demand Forecast page
6. Dual-Pipeline Comparison page
7. Recommendations page
8. What-If Simulator page
9. A terminal/console screenshot showing a pipeline script running successfully
   (e.g. join_data.py or compare_classifications.py output)

Name them like `01_executive_dashboard.png`, `02_menu_intelligence.png`, etc.
so they sort in the order a grader would naturally click through the app.
